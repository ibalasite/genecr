# 元旦跨年活動 SCRUM 故事卡

## Epic：元旦跨年限時活動 — 倒數、煙火、紅包雨、好運轉盤、儲值加碼
於 12/31-1/2 期間推出跨年主題活動，含倒數計時、煙火特效、限時儲值加碼、紅包雨、新年轉盤等機制，刺激玩家活躍與儲值，並透過後台參數與代理商成本控管確保不造成代理商損失。

**總計**：10 張故事卡，預估 49 點。

---

## 🏗️ 基礎建設

### Story #1：建立活動服務骨架
**作為** 後端工程師，**我想要** 建立 Node.js + Express 活動服務，含 MySQL 與 Redis 連線，**以便** 所有跨年活動 API 都掛在此服務下統一管理

**驗收標準**：
- [ ] 服務能啟動並通過 /health 健康檢查
- [ ] MySQL/Redis 連線參數可由環境變數覆寫
- [ ] 活動時間區間（12/31-1/2）可由設定檔調整

- **Story Points**：3
- **負責團隊**：`Server`- **技術備注**：Express + mysql2/Sequelize + ioredis；活動參數放 Redis hash 快取

---

### Story #2：活動資料表與設定
**作為** 後端工程師，**我想要** 設計 event_config / event_user_progress / event_reward_log 等資料表，**以便** 完整紀錄活動參數、玩家進度與發獎紀錄以便對帳

**驗收標準**：
- [ ] MySQL schema 建立並有 migration 腳本
- [ ] reward_log 含 agent_id 欄位以便分潤對帳
- [ ] 所有時間欄位使用 UTC 並於 API 層轉時區

- **Story Points**：5
- **負責團隊**：`Server` · `DBA`- **技術備注**：Sequelize migration；reward_log 加 idempotency_key 防重發

---

### Story #3：後台活動參數與代理商成本上限
**作為** 後端工程師，**我想要** 提供後台 API 設定加碼比率、紅包池上限、轉盤獎項機率與代理商成本上限，**以便** 營運可即時調整避免代理商損失

**驗收標準**：
- [ ] 可設定每代理商每日成本上限
- [ ] 超過上限時自動降級獎勵或停發
- [ ] 所有變更寫入 audit log

- **Story Points**：5
- **負責團隊**：`Server` · `Ops`- **技術備注**：Express admin route + JWT 權限；Redis 快取參數 TTL 60s

---

## 🎮 遊戲邏輯

### Story #6：限時儲值加碼活動
**作為** 後端工程師，**我想要** 在活動期間針對指定儲值檔位給予加碼點數，**以便** 刺激玩家儲值衝量

**驗收標準**：
- [ ] 加碼比率可由後台設定並支援分時段
- [ ] 加碼成本納入代理商成本上限計算
- [ ] 儲值失敗不發加碼，發放具冪等性

- **Story Points**：5
- **負責團隊**：`Server` · `Payment`- **技術備注**：Express webhook 接金流；mysql2 交易 + Redis 分散鎖防重發

---

### Story #7：跨年紅包雨機制
**作為** 後端工程師，**我想要** 實作紅包雨開場、限額、點擊扣庫存與發獎邏輯，**以便** 提供高互動的限時福利刺激上線

**驗收標準**：
- [ ] 每場紅包雨總額由後台設定
- [ ] 玩家領取上限可設定
- [ ] 庫存歸零後不再發放，全流程具冪等性

- **Story Points**：8
- **負責團隊**：`Server` · `Client`- **技術備注**：Redis Lua decr 控制原子扣量；MySQL 異步落庫

## 🏆 獎勵系統

### Story #8：新年好運轉盤
**作為** 後端工程師，**我想要** 提供每日免費 + 儲值獲得抽獎次數的好運轉盤，**以便** 延長活動黏著並導引儲值

**驗收標準**：
- [ ] 獎項機率可由後台設定且總和=1
- [ ] 保底機制：N 抽必中指定獎
- [ ] 抽獎結果與庫存於同一交易內完成

- **Story Points**：5
- **負責團隊**：`Server` · `Client`- **技術備注**：Sequelize transaction；Redis 快取機率表；別名法抽樣

---

### Story #9：代理商成本守門與分潤對帳
**作為** 後端工程師，**我想要** 即時統計各代理商活動成本並在超標時自動收斂獎勵，**以便** 確保不讓代理商損失

**驗收標準**：
- [ ] 每筆發獎累加至 agent_cost Redis counter
- [ ] 超過上限切換降級策略並通知營運
- [ ] 每日產出對帳 CSV 供財務

- **Story Points**：5
- **負責團隊**：`Server` · `Finance`- **技術備注**：ioredis INCRBYFLOAT + 每日落 MySQL；Express cron 報表
